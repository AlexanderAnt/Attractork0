# Сильная тётка

- Немолодая, типаж «Служебного романа» / «Москва слезам не верит»: сильная, независимая, подруги повыскакивали, а она одна.
- Из промышленности. Через неё летёха ведёт линию [[Горючка|горючки]].
- По инструкциям, которые оставил ей [[Летёха|летёха]], передаёт его настоящий [[Доклад летёхи|доклад]] [[Отец Сынули|отцу Сынули]].
- Кто она летёхе – не решено.
