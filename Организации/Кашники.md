# Кашники

- Члены [[Коллегия|коллегии]], их полсотни. Сидят в [[Зал заседаний|зале]] сзади, министры спереди.
- Приезжают на съезды издалека, на лифте; в [[Столовая|столовой]] гудит их зал.
- [[Хозяин]] при входе по привычке пересчитывает их.
- Перерабатывают их уже после [[Переворот|переворота]], это надолго. Хозяин рассылает их по их секторам ([[Х16 Клетка]]).
